# おばけの休憩室（Godot 版・Variant B「眠りのリズム」）

夜の庭で、おばけたちと暮らす。いつも同じころに、よく眠ると「リズム」が満ちて、庭が育つ。
シフトの日は、仕事の種類のポイと、その店にちなんだ飾りが庭に届く（ブースト。長く働いても増えない）。

## 動かす

```
godot --path ~/dev/obake-godot-b              # タイトルから
OBAKE_DEMO=play godot --path .                # 自動で何日も遊ぶ（確認用）
OBAKE_START=garden OBAKE_FF=21 godot --path . # 3週間すすめた庭から
```

## 1日の流れ

1. 朝：ゆうべの眠りのまとめ（リズム・めぐみ）→ 光る玉がかえる → 庭が育つ
2. 昼：シフトに行く（ポイと飾り）／休む
3. 夜：川べりでおばけすくい（毎週日曜は満月の夜）
4. 寝る：夜の過ごし方を選ぶ（いつもの時刻・もうひと回り・夜店…）。よく眠ると夢（羊かぞえ／星ひろい）
