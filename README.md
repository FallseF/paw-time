# Paw Time（Godot 版・Variant A「すくいと収集」）

猫おばけの休憩室。

夜の川べりで光る玉をそっとすくう。朝、玉がおばけにかえる。かぶったおばけは育ち、ていねいにすくった分は「かけら」になって、ポイ工房でポイや休憩室のかざりを作れる。
毎朝紙のポイが2本もらえるので、仕事がなくても遊べる。働いた日は仕事の色のポイ（何時間でも2本まで）、よく寝た朝はポイが強くなり玉がよく育つ。

## 動かす

```
brew install --cask godot   # 初回だけ
godot --path ~/dev/obake-godot-a --resolution 360x640
```

くわしい遊び方・確認用のコマンド・バランスの数字は REPORT.md。

## 1日の流れ

1. 朝：すくった玉がかえる（よく寝た朝は★がひとつ増えて、よく育つ）
2. 休憩室：今日のシフト（見本の記録）に行くと、仕事の色のポイ。はじめての店・仕事ならきらきらポイ
3. 夜の川べり：押して水に入れ、そっと玉の下へ、離してすくう。土曜は大すくい祭り
4. 寝る：睡眠時間で、明日のポイの強さと玉の育ち方が決まる

## 音
