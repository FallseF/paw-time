# Paw Time 仕様書

**バイトの日は、おばネコも一緒に働く。おばネコが疲れたら、今日はおしまい。**

働く人のためのゲーム。実際のシフトが、猫おばけ（おばネコ）を集めて島を育てるゲームのブーストになる。長く働いても得はしない。働きすぎは、一緒に働くおばネコが疲れることで止める。
Team Dry Grape（大山慶悟・青木悠登・小柳璃紗）／Recruit Innovation Cup 2026。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| 公式テーマ | 未来の仕事にイノベーションを起こすプロダクト |
| 価値観 | 労働を楽しいものに彩る。イービルな商品にしない |
| 対象 | **短期・スキマバイトで働く人**（いろんな店を回る人） |
| 長期で働く人 | 専用機能は作らない。シフトを手で登録し、求人の知らせを切れば遊べる |
| 審査向け | 画面は英語が既定、日本語は切り替え |

### 守る決まり
1. **長く働くほど得をする設計にしない。** 仕事のブーストは時間によらず一定。
2. **働きすぎを止める。** おばネコが疲れて「いっしょに帰ろ」と言い、それ以上は何も増えない。
3. **賃金には一切触らない。** ゲーム内通貨と現金を交換しない（労基法24条・資金決済法の論点、芯との矛盾）。
4. **課金は見た目の品の買い切りだけ。** ガチャ・時短・換金・遊びの有利はなし。今は見本（押すと「準備中」）。
5. **収益はお店側から。** 求人掲載、シフトの穴埋め、匿名レビューの集計。働く人は無料。

## 2. 1日の流れ（コアループ）

1. **昼：シフト** — 実際のバイト中、おばネコもゲーム内の小さな店で働き、肉球コインを稼ぐ。終わるとポイ（すくい網）がもらえる。
2. **勤務後：ひとことレビュー** — 10秒で店の感想。ポイ +1。
3. **夜：おばけすくい** — 川辺の池で光るガラス玉を金魚すくいのようにすくう。
4. **朝：孵化** — 玉が割れて中身が出る（睡眠の入力はない。夜が明けると孵る）。
5. **いつでも：島とキセカエ** — 材料で島を育て、服でおばネコを着せ替える。

働かない日も、毎日のすくい・島・キセカエ・おさらい・チャットで遊べる。シフト中はおばネコも出勤中で、ゲームでは遊べない（今のシフトのお店とのチャットだけ開ける）。

**睡眠の仕組みは入れない**（2026-09-26 に削除）。働きすぎの対策は「おばネコが疲れる」ことだけで行う。

## 3. 機能

### 3.1 はじめの流れ（オンボーディング） [済]
1. インストール
2. **マイおばネコ診断**（MBTI風、12問・16タイプ）→ 自分だけの特別な子が出る [済]
3. 見本のカフェのシフトで遊び方を体験（ポイ +2）
4. 最初のすくい（必ずおばネコが出る）→ 夜 → 朝の孵化
5. 島の説明（カード4枚）
6. **働く条件の入力**：場所・時間・時給・支払いの形（日払い／週払い／月払い）。口座やカードの番号は聞かない・残さない
7. おばネコが**毎日3〜4件の求人**を知らせる（今は見本データ64件、カードに見本と表示）
8. 受ける → おばネコが喜ぶ → シフトに登録 → **Googleカレンダーのリンク**と `.ics`
9. 断る → おばネコは肩をすくめるだけ（罰なし）
10. 長期の人向け：シフトを自分で入れる／求人の知らせを切る

### 3.2 一緒に働く（過剰労働の歯止め） [済]
- シフト中（登録シフト、または「仕事に行く」「ただいま」ボタン）におばネコが働き、肉球コインを稼ぐ。アプリを閉じても進む。
- 疲れはメーターではなく見た目で出す：元気 → 傾く → 汗 → 「z z」 → へたりこむ。
- シフト終了：コインが財布へ。ポイ2つ（時間によらず一定、1日1回）。レビューへ。

| 数字 | 値 |
|---|---|
| 稼ぎ | 30コイン/時 × 元気（1−(時間/7.5)²） |
| 1日の上限 | 180コイン。7.5時間を過ぎたら0 |
| 残業した翌日 | おばネコがまだ疲れていて、稼ぎ ×0.85 |
| 例（1日） | 4時間 → 119、7.5時間 → 165、9〜12時間 → 165 |
| 例（週5日） | 5時間/日 → 700、7.5時間/日 → 825、10時間/日 → 725 |

### 3.3 おばけすくいと玉の中身 [済]
- 光る玉はガラスの殻・渦を巻く光・中で眠る子猫の影の3Dモデル。
- **玉の中身は基本が材料、おばネコはレア：**

| 中身 | 割合（仮） |
|---|---|
| 島の材料 | 70% |
| 服 | 20% |
| おばネコ | 10% |

- はじめてのすくいは必ずおばネコ。7晩出なければ次の夜に必ず1匹（回数は画面に出さない）。
- おばネコ入りの玉は光り方が違い、朝の孵化も特別な演出。材料・服はまとめてすぐ開く。

### 3.4 図鑑（おばネコ） [済]
- ふつう5種 + **レア30体**（すべて3Dモデル）。
- レアは暮らしぶりで出る（雨の日のシフト、満月の夜、忙しい週のあとにしっかり休む など）。働いた時間の長さでは出ない。1晩に2体まで。玉の10%とは別枠。

### 3.5 島づくりとシェア [済]
- 休むほど島が段階的に育つ（段10まで）。診断の子が島のあるじ。 [済]
- **島のコードをURLで共有**（`#island=`）。他の人の島におでかけできる。 [済]
- 島の飾り40点以上（AAA品質）、材料で建てる。 [済]
- **島の拡張**：岸の「＋」から、材料とコインで陸地や小島を足す（6〜8回まで）。共有コードにも入る。 [済]
- **乗り物**：他の人の島へ行くとき、夜の海を渡る場面（3〜5秒、飛ばせる）。いかだ（最初から）・手こぎボート・フェリー・水上飛行機・ヘリ、ほかに特別な1〜2種。**見た目だけ**で、速さやご褒美の差はない。自分の島の桟橋に停まり、来た人に見える。 [済]

### 3.6 キセカエ [済]
- 服と小物50点、6か所（頭・顔・首・体・手・背中）。キセカエの部屋で試着・保存。マイおばネコは体の色を6色から選べる。
- 入手：仕事の制服（その仕事をはじめてやったとき）、休みの日や友達の島を訪ねた回数などの節目（連続記録は使わない）、図鑑、玉の中身、肉球コインのお店（19点）。
- 特別な棚3点：値段は見えるが「準備中」。支払いなし。

### 3.7 通貨

| 名前 | 手に入れ方 | 使い道 |
|---|---|---|
| ポイ（すくい網） | シフト終了（2つ）、レビュー（1つ）、見本のシフト | 夜のすくい |
| 肉球コイン | 一緒に働く（主）、めあての達成（+10） | 島の飾り・拡張・服・乗り物 |
| 島の材料 | 玉の中身 | 島の飾り・拡張・乗り物 |

どれも現金とは交換しない。

### 3.8 お店の島（実績で育つ） [統合中]
- お店ごとの島。働いた人のレビューのタグ（時間どおりに帰れる・休憩がとれる・指示が分かりやすい・給料が遅れない・雰囲気がいい・また働きたい など7種）ごとに目印があり、票の**数**で3段まで育つ（3票・8票・16票）。
- **増えるのはプラスだけ**。悪い飾り・しおれ・店どうしの順位はない。割合ではなく数で決めるので、評価が増えて目印が消えることはない。
- お金では飾れない。お店が決められるのは看板・色・ひとことの価値観だけ。画面に「Based on N worker reviews」。
- 求人カードの「Visit this shop's island」から乗り物で行ける。目印をタップすると「Workers said: Left on time ×16」。

### 3.9 前の晩の声かけ・また来てほしい [統合中]
- シフトの前の晩に「明日10時、カフェやで。待っとるで」、当日の朝に「9時半に出る？」。ゲーム内だけ。休んでも罰・連続記録なし。
- ★4以上のレビューをした店から誘いが届き、毎日の求人の先頭に「Invited」で並ぶ。

### 3.10 おさらいとスキルの記録 [統合中]
- レジ・洗い場・ホール・キッチン・品出しの練習ミニゲーム（1〜3分、★3まで）。どの店でも通じる一般スキルだけ。
- まちがえても言い直すだけ。罰・急かす制限時間・順位なし。ご褒美は初回だけ（★1で制服、★2・★3でポイ1本）。
- 本物のシフトは**回数**で経験になる（時間では数えない）。記録は店を変わっても消えない。求人カードに「Your skill: Register ★ · 3 shifts」。
- **おさらいは任意**。お店が命じる事前研修は労働時間にあたり賃金が要るため、店ごとの手順はシフトの中で行う。

### 3.11 審査員用の3分コース [案]
- タイトルの「3-minute demo」から：求人1件を受ける → シフト早送りでおばネコが疲れて止める → レビュー → すくい（必ずおばネコ）→ 孵化 → 「リクルートの画面」で自分の操作が数秒で「Live now」に並ぶ。

### 3.12 行動データの送信とリクルート向け画面 [制作中]
- ゲームから匿名の出来事（開いた日、求人を見た・受けた・見送った、シフト、疲れて止めた、レビュー、おさらい、店の島の訪問 など）を送る。詳しくは 8章。
- リクルート向け画面：毎日開く率、仕事を探していない日に開かれた率、継続率、求人の流れ、働きすぎの歯止め、店側の指標、働いたあとの信号、試験運用の提案。Live（試遊した人の本物）と、12週間のシミュレーション（作ったデータ・全グラフに synthetic 表示）を切り替える。

## 7. お店（お金を払う側）にとっての価値

| お店の悩み | Paw Time の答え |
|---|---|
| 登録者は多いのに、実際に動く人が少ない | 仕事を探していない日もゲームを毎日開く。その場でおばネコが合う求人を3〜4件届ける |
| 急な欠員 | 近くにいて、空いていて、その仕事の印を持つ人に知らせる。**疲れている人・その日の上限まで働いた人には届けない**（これ自体が品質の保証） |
| 合わない人が来てすぐ辞める | 自己申告ではなく行動（おさらいの結果、来た率、お互いの評価、応募の前の関心）で合わせる |
| 初日の教える手間 | おさらいで一般スキルを先に身につけた人が来る |
| 良い人を長く確保したい | 3回以上来て、お互いに良い評価をつけ合った人にだけ、お店から長期で働かないか声をかけられる（本人が選ぶ） |
| 掲載の営業に手間がかかる | 「あなたの島を今週N人が見に来た」「一番押された目印」を集計で見せ、掲載の入口にする |

## 8. データの使い方

### 線引き
**データは社内で最大限使う。お店に渡すのは結果と集計だけ。人ごとの点数や順位はお店に渡さない。**

| | 中身 | 根拠・条件 |
|---|---|---|
| 社内でフル活用 | おさらいの結果、来た率、お互いの評価、求人を受けた・見送った、店の島の訪問、チャットから取り出した印（困りごと・気持ち・仕事の好み） | 利用目的を公表した範囲で使う（個人情報保護法 17・18条）。**使い道は「誰に先に求人を届けるか」** |
| 集計して提供 | 店の島の訪問数と押された目印、困りごとの傾向、集まりやすい曜日・時間、働いたあとの信号 | 5人未満の集計は出さない |
| 本人が選んだら提供 | スキルの印、来た回数、ちゃんと来た率 | 第三者提供は本人の同意（同法27条）。最初は切ってあり、いつでも取り消せる。見せると良い仕事が先に届く |
| やらない | 人ごとの点数・順位の提供、疲れ・チャットの文の提供、病歴など要配慮個人情報を学習に使う | 同法19条（不適正利用の禁止）、20条2項（要配慮個人情報の取得には同意） |

- 仕事探しの法律：職業安定法 5条の5（必要な範囲・目的の明示。本人の同意があれば例外）。事業開始時は特定募集情報等提供事業の届出を行う。
- 送らない情報：名前、細かい場所、自由に書いた文。識別はランダムな番号だけ。ゲーム内にお知らせと送信を止めるスイッチを置く。
- おばネコのチャット：
  - **社内で使う**（合う仕事探し・改善）。はじめて開いたときに正直な同意カードを出す：「おばネコは話したことを覚えて、合う仕事探しに使う。お店にあなたの言葉は渡さない」。
  - **ないしょモード**（Just between us）：オンの間は何も取り出さず、何も送らない。
  - 送るのは端末の中で取り出した**決まった種類の印だけ**（休憩がとりにくい・どなられた・給料が遅れた・指示が分かりにくい・忙しすぎる・新しい仕事が不安・仲間が良かった・お客さんが良かった・もっと働きたい・減らしたい・裏方が好き・接客が好き）。生の文は送らない。健康・家族・つらい話は印にしない（要配慮個人情報の取得には事前の同意が要る：同法20条2項）。
  - **お店に出すもの**：本人が「名前を伏せて伝える」と選んだ困りごと、同じ種類の声が5人以上そろった集計（週単位）、良い声の集計（5人以上）。
  - ハラスメントは運営への匿名通報にできる。つらい話には相談窓口（厚労省「まもろうよ こころ」）を案内する。
- 参考：キャラクターと話すアプリは、会話を学習や広告に使うことで規制を受けている（Replika にイタリアの監督庁が500万ユーロの罰金〔2025年5月〕、米FTCが7社を調査〔2025年9月〕）。Paw Time は「おばネコは、あなたの言葉をお店に渡さない」を打ち出す。

### 働いたあとの信号（仮説）
ふつうの求人アプリは、仕事が決まると開かれなくなるため「開かない」に意味がない。Paw Time は働いたあとも毎日開かれるので、**いつもどおりの基準**ができ、「いつもと違う」が読める。

| 行動の変化 | 読める仮説 |
|---|---|
| 毎日開いていた人が、ある店で働いたあと開かなくなった | その店が合わなかった |
| 働いたあと、その店の島をもう一度見に行った | また行きたい |
| 同じ店の誘いを何度も見送る | 口には出さないが戻りたくない |
| 新しい仕事の前におさらいを何度もする | 不安が大きい → 初日の支えを厚くする |

- 1人分では判断しない。同じ店で働いた人の集計（5人以上）で見る。お店に「誰が」は出さない。
- 気持ちを当てたとは言わない。おばネコは「昨日どうやった？」と聞くだけで、答えは自由。
- 試験運用で、翌日の戻り率と「また来た率」「辞めた率」が重なるかを確かめる。

## 9. リクルートにとっての価値

### 背景（公開情報）
- リクルートは2025年3月24日、スポットワークの新サービス『タウンワークスキマ（仮称）』の開発中止を発表した（理由は「開発優先順位の観点」）。
- スポットワークの利用者は2025年2月時点で約3200万人、前年から2倍以上（スポットワーク協会。登録の合計なので重複を含む可能性）。
- リクルートの人材領域の柱は「Simplify Hiring」。日本では Indeed PLUS で求人を配信している。

### 仮説のつながり
1. 今の求人マッチングは「応募・採用」を当てにいっている。働き始めてから合ったかは返ってこない。
2. Paw Time は働いたあとも毎日開かれるので、「合ったか」の信号（翌日の戻り、店の島の再訪、誘いの受諾、また来た）が取れる。
3. これを「良い組み合わせ」の答えとして学習すれば、「応募されやすい求人」ではなく「合う求人」を上に出せる。
4. お店が一番お金を払いたいのは応募の数より定着。定着が上がれば、掲載の価値と継続率が上がる。
5. 働いたあとの信号はスポットワークに限らず、長期の採用にも使える。

**一番弱い輪は3**（アプリを開くかどうかが、合ったかどうかと重なるか）。試験運用で最初に確かめる。

### 事業への効き方（仮説）

| 事業 | 効き方 |
|---|---|
| Indeed（検索とマッチング） | 「雇ったあとに合ったか」を答えにして並べ方を良くする |
| Indeed PLUS／タウンワーク | 配信された求人から、おばネコが合うものを選んで届ける「毎日開かれる入口」になる |
| Air 系（お店向けの道具） | Airシフトの空き枠を急な穴埋めの知らせにする。お店に翌日の戻り率・改善のヒントを集計で渡す |

- リクルートのデータがゲームに入ってくる向き（求人、シフトの空き枠）は、働く人の個人情報を含まないので進めやすい。
- ゲームのデータがグループ内の他サービスへ出ていく向きは、本人の同意、または共同利用の事前告知（個人情報保護法27条5項3号）が要る。店ごとの集計を主にする。

### 試験運用の提案（案）
- お店3〜5軒 × 4週間。
- 測るもの：毎日開く率（DAU/MAU）、仕事を探していない日に開かれた率、埋まる率、急なお休み、また来た率、レビューの回答率、翌日の戻り率と「また来た率」の重なり。
